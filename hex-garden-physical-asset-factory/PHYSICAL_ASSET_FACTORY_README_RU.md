# Physical Asset Factory V11

Процедурный Blender-пайплайн: одна керамическая ячейка и все 15 элементов.
Источники — геометрия, шейдеры и SVG. Итоговые PNG не дорисовываются нейросетью
и не используются как master-исходники. Направление задают изображения в `art/reference`.

## Запуск

Нужен Blender с Cycles. Проверено в Blender 5.2 на RTX 2060. Видеокарта выбирается
автоматически; если совместимого устройства нет, используется CPU. Системный
Python и установка Pillow для основных команд **не нужны**.

Из этой директории:

```powershell
# Проверить манифест, символы и реальные объекты Blender.
powershell -ExecutionPolicy Bypass -File .\test_physical_assets.ps1

# Пересобрать все 16 PNG и проверить результат.
powershell -ExecutionPolicy Bypass -File .\build_physical_assets.ps1

# Быстрая итерация: один или несколько элементов, с проверкой выбранных PNG.
powershell -ExecutionPolicy Bypass -File .\build_physical_assets.ps1 -Only "water,fire"
powershell -ExecutionPolicy Bypass -File .\build_physical_assets.ps1 -Only board-cell

# Поле и семейство всех фишек на сукне, плюс редактируемая .blend-сцена.
powershell -ExecutionPolicy Bypass -File .\preview_physical_assets.ps1
```

Blender ищется в PATH, `BLENDER_EXE` и `Program Files/Blender Foundation` на локальных
дисках. Для нестандартной установки передай `-BlenderExe "D:\...\blender.exe"`.
`-ExecutionPolicy Bypass` относится только к запускаемому процессу PowerShell.
Ошибки Blender и проверок завершают команду ненулевым кодом; ложного `Done` нет.

## Результаты

- `public/assets/physical-premium/board-cell.png`
- `public/assets/physical-premium/piece-*.png` — 15 центрированных RGBA PNG 1024×1024.
- `public/assets/physical-premium/asset-factory-manifest.json` — SHA-256 исходников
  и каждого PNG. Выборочная сборка сохраняет записи остальных элементов. Проверка
  обнаруживает устаревшие либо вручную заменённые файлы.
- `art/physical-premium-preview/board-preview.png` — 37 ячеек, поле полностью в кадре.
- `art/physical-premium-preview/piece-family-preview.png` — все 15 элементов.
- `art/physical-premium-preview/physical-asset-factory-preview.blend` — сцена семейства.
- `art/physical-premium-preview/runtime-contact-sheet.png` — QA-лист, собранный из
  настоящих runtime-PNG; нижний ряд показывает символы при диаметре шара около 50px.
  Его можно обновить обычным Python с Pillow:
  `python tools/physical_assets/render_contact_sheet.py`.

Порядок элементов на превью, слева направо:

| Ряд | Элементы |
| --- | --- |
| 1 | Salt, Air, Fire, Water, Earth |
| 2 | Quicksilver, Gold, Silver, Copper, Iron |
| 3 | Tin, Lead, Vitae, Mors, Quintessence |

Сборка пишет только в эту фабрику. Подключение PNG к Phaser выполняется отдельно.
В публичные режимы Quintessence не добавляется; это часть полного внутреннего набора.
В общем 3D-превью возможны отражения соседних фишек. В runtime-PNG отражается нейтральная
сцена с той же ячейкой и сукном, без случайного соседнего элемента.

## Что исправлено

1. **Материал ячейки действительно назначен всем граням.** Boolean создавал пустой
   слот 0; керамика добавлялась в слот 1, а все грани оставались в слоте 0. Именно
   поэтому V9/V10 меняли crackle и цвет, но рендерили серый материал Blender.
2. **Символы следуют поверхности сферы.** Прямые SVG-сегменты сначала дробятся,
   затем проецируются. Раньше проецировались только концы и хорда проходила внутри
   шара: Salt почти исчезал, прямые участки других символов обрывались.
3. **Заполненные формы тоже проецируются.** Лучи Fire и листья имеют тонкую заполненную
   поверхность с правильной ориентацией нормалей. Это настоящая геометрия, не плоская
   наклейка через шар. Учтён индексный результат `tessellate_polygon` в Blender 5.2.
4. **Посадка без пересечения чаши.** Радиусы 1.00 / 0.79 / 0.68, высота 0.84,
   pointy-сетка и её шаг 0.996 сохранены. Центр шара поднят с 0.18 до 0.312:
   расстояние между центрами + радиус шара теперь меньше радиуса чаши.
5. **Согласованный свет.** Источники направлены на предмет; удалённый студийный свет
   сохраняет угловой размер и освещённость при масштабировании. Заполняющие лампы
   не создают лишние белые диски в стекле. Поле больше не обрезается камерой.
6. **Разные физические материалы.** Стекло имеет отдельную уменьшенную сердцевину
   и оболочку, Air — опаловые переливы, Earth — минеральную структуру, металлы —
   патину и микрорельеф. Старый вариант включённой оболочки накладывал две сферы
   одного радиуса. Теперь совпадающих поверхностей нет.
7. **Реальные проверки вместо фиксации случайных настроек.** Тесты проверяют
   назначения материалов после Boolean, целые линии на сфере, все 15 типов,
   заполненные SVG, посадку, направление света, сетку и сохранность build-записей.

## Где настраивать

- `art/physical-premium-manifest.json`: палитра, roughness, crackle, радиусы, свет,
  качество рендера и индивидуальная ширина символов.
- `art/physical-icons/*.svg`: символы. Абсолютные M/L/H/V/C/Q/Z; неподдерживаемая
  команда вызывает ошибку. `fill="currentColor"` включает заполненную простую
  замкнутую форму. Отверстия в compound-path не поддерживаются.
- `tools/blender/physical_asset_factory.py`: геометрия, шейдеры и рендер.

Cycles: 384 samples для PNG, 192 для 3D-превью, denoise включён. Оценивать надо и
1024px исходник, и фишку при ширине 50–90px: мелкая фактура подчинена читаемости
символа. После изменения общих материалов/света пересобери весь набор.

`.scratch`, кэши Python/OptiX и `.blend`-резервные файлы исключены из Git.
Pillow из `requirements-physical-assets.txt` нужен только для запуска PNG-проверки
обычным Python вне Blender; сам build использует Blender.
