# Sigmar's Garden — rules and progression lab

Phaser-стенд для проверки правил, генерации и основной прогрессии. Визуальное оформление, ассеты, подсказки, звук, обучение, реклама и таблица лидеров пока намеренно не разрабатываются: текущая цель — получить правильную и устойчивую механику уровней.

## Запуск

Нужны Node.js 20+ и pnpm:

```powershell
pnpm install
pnpm dev
```

Проверка и production-сборка:

```powershell
pnpm test
pnpm build
pnpm preview
```

## Режимы

Игра открывается минималистичным меню с тремя независимыми режимами:

- `CAMPAIGN` открывает экран выбора всех 60 уровней;
- `STANDARD / ENDLESS` запускает прежний бесконечный режим с полными стандартными раскладками;
- `Q MODE / ENDLESS` запускает прежний бесконечный режим с Quintessence.

Номер уровня в обоих бесконечных режимах не ограничен. Их исходный контракт сохранён: 55 фишек, 91 клетка и оригинальные симметричные семейства `SIXFOLD`, `THREEFOLD`, `TWOFOLD`, `OUTER-RINGS`.

На поле: `←`/`→` — доступные уровни, `R` — перезапуск, `Esc` — возврат к выбору уровней или в меню.

## Основная кампания

Кампания генерируется отдельно от бесконечных режимов и состоит из шести глав:

| Уровни | Поле | Новая механика |
| --- | ---: | --- |
| 1–8 | 37 клеток | четыре обычные стихии вводятся постепенно |
| 9–16 | 37 клеток | Salt |
| 17–26 | 61 клетка | пара Vitae/Mors |
| 27–38 | 61 клетка | Quicksilver и цепочка металлов; Gold появляется только после полной цепочки |
| 39–50 | 91 клетка | полный стандартный набор из 55 фишек |
| 51–60 | 91 клетка | Quintessence, затем полный Q-набор |

При первом запуске доступен только уровень 1. Победа отмечает его как `DONE` и открывает ровно следующий уровень как `PLAY`; остальные остаются `LOCK`. Переход стрелкой и клик не позволяют обойти блокировку. Прогресс хранится в `localStorage` браузера и восстанавливается после перезагрузки.

Каждый уровень зависит только от seed и номера. Генератор сначала строит раскладку и прямой порядок удаления, затем воспроизводит сертификат через публичный `SigmarsGardenBoard.select()`. Поэтому все выдаваемые уровни гарантированно имеют хотя бы одно полное решение.

В записи уровня сохраняются измеряемые показатели: заполненность поля, число ходов, количество свободных фишек и легальных ходов вдоль сертификата. Они нужны для дальнейшей настройки кривой сложности без изменения правил.

## Правила и нижняя панель

На поле используются исходные внутренние обозначения `Sa`, `Ai`, `Fi`, `Wa`, `Ea`, `Hg`, `Pb`, `Sn`, `Fe`, `Cu`, `Ag`, `Au`, `V`, `M`, `Q`. Затемнённые фишки недоступны, выбранные обведены белым.

Нижняя панель показывает остатки типов и цепочку `Pb → Sn → Fe → Cu → Ag → Au`; нажатие на тип подсвечивает такие фишки на поле. В Q-раскладках `Q` стоит вместе с четырьмя стихиями, а `Hg` остаётся перед цепочкой металлов.

Цепочка металлов соблюдается строго. После `Fe` открывается `Cu`, а `Au` может открыться только после `Ag`. Если золото присутствует в кампании, сертификат всегда оставляет его на последний ход.
