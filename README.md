# Sigmar's Garden — rules lab

Минимальный Phaser-стенд для проверки игрового поля, правил удаления и генерации уровней. Это пока не оформленная игра: продуктовый интерфейс, ассеты, подсказки, звук, обучение, сложность, реклама и таблица лидеров намеренно удалены.

## Запуск

Нужны Node.js 20+ и pnpm:

```powershell
pnpm install
pnpm dev
```

Проверка и production-сборка:

```powershell
pnpm test
pnpm build
pnpm preview
```

## Что находится на экране

- поле из 91 гексагональной ячейки;
- 55 фишек с исходными обозначениями `Sa`, `Ai`, `Fi`, `Wa`, `Ea`, `Hg`, `Pb`, `Sn`, `Fe`, `Cu`, `Ag`, `Au`, `V`, `M`, `Q`;
- затемнённые недоступные фишки и белая обводка выбранных;
- рабочая нижняя панель остатков `Sa`, стихий и `Hg`, а в Q MODE также `Q`, а также цепочки `Pb → Sn → Fe → Cu → Ag → Au`; нажатие на тип подсвечивает все такие фишки на поле;
- предыдущий уровень, перезапуск, следующий уровень;
- переключатель `STANDARD` / `Q MODE`.

В заголовке также показано семейство геометрии: `SIXFOLD`, `THREEFOLD`, `TWOFOLD` или редкое `OUTER-RINGS`.

Клавиши: `←`/`→` — уровни, `R` — перезапуск, `V` — вариант раскладки.

## Уровни

Каждый номер уровня детерминированно генерирует проходимое поле в Web Worker. `.dat` в браузере не нужен. Генератор создаёт структурированную маску с симметрией 60°, 120° или 180°, назначает ей новый порядок удаления, сохраняет сертификат решения и до возврата уровня воспроизводит его через то же публичное API, которым пользуется игра.

Типы фишек распределяются несимметрично, поэтому обычные уровни не выглядят как искусственные орнаменты, хотя пустые и занятые клетки имеют скрытую вращательную структуру. Редкая форма `OUTER-RINGS` состоит из золота в центре и двух полностью заполненных внешних колец.

Цепочка металлов: `Pb → Sn → Fe → Cu → Ag → Au`. После железа открывается медь; золото может открыться только после серебра. В сгенерированных сертификатах серебро — последняя пара, золото — последний ход.

`STANDARD` содержит базовый набор из 55 фишек. `Q MODE` заменяет часть пар Vitae/Mors и стихий двумя группами Quintessence; размер поля остаётся равен 55. Это варианты правил, а не выдуманные уровни сложности.

Точный контракт правил и результаты повторной сверки с исходниками записаны в [RULES_AUDIT.md](RULES_AUDIT.md). Ограничения для следующей работы — в [AGENTS.md](AGENTS.md).
