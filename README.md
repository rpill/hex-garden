# Hex Garden — functional puzzle build

Hex Garden — браузерная головоломка на Phaser + TypeScript для Яндекс Игр. Сейчас проект находится в фазе **функциональной приемки**: правила, 50-уровневая кампания, Daily, Endless, помощь, сохранения и адаптивный UI проверяются до возобновления финального арт-продакшна.

## Источники истины

Если документы расходятся, фактическое состояние определяют код и тесты.

## Запуск

Нужны Node.js 20+ и pnpm:

```powershell
pnpm install
pnpm yandex:dev
```

`pnpm yandex:dev` запускает Vite через официальный `@yandex-games/sdk-dev-proxy` с Yandex mocks для SDK/player data/rewarded сценариев. `pnpm dev` — обычный низкоуровневый Vite-запуск.

Нормальный validation gate:

```powershell
pnpm test
pnpm typecheck
pnpm build
```

`pnpm author:campaign` используется **только для authoring кандидатов кампании**. Нормальный build/test не должен регенерировать `src/data/campaign-levels.json`.

Подробнее: [VALIDATION.md](VALIDATION.md).

## Публичные режимы

### Tutorial

Отдельное интерактивное обучение перед кампанией. Оно объясняет базовое совпадение, геометрическую доступность и панель оставшихся атомов, после чего ведёт на Level 1.

### Campaign

- ровно **50 фиксированных уровней**;
- **5 глав по 10 уровней**;
- уровни хранятся в `src/data/campaign-levels.json` и не генерируются заново во время обычной игры;
- используются полные правильные hex-пластины на **37 / 61 / 91 клетку**;
- правила Garden одинаковы на протяжении кампании; фиксированные карточки при первом появлении механики только объясняют стандартное правило и не меняют его;
- прохождение открывает следующий уровень последовательно.

У каждого уровня два состояния прогресса:

- `SOLVED` — поле очищено;
- `CLEAN` (`◆`) — поле очищено без Hint или Rescue в этой попытке.

Undo и Restart не портят Clean. Hint или Rescue делают только текущую попытку assisted; уровень можно позже перепройти Clean.

Mastery зависит от количества Clean:

| Clean | Rank |
| ---: | --- |
| 0 | Novice |
| 5 | Apprentice |
| 15 | Adept |
| 30 | Strategist |
| 40 | Expert |
| 50 | Master |

После решения всех 50 уровней Continue переключается на ещё не закрытые Clean-уровни.

### Daily

Daily появляется после **5 решённых уровней Campaign**.

- одна детерминированная задача на текущую дату;
- календарная граница — `00:00 Europe/Moscow`;
- неделя — понедельник–воскресенье;
- используется trusted platform clock;
- сохраняются Solved/Clean для последних 90 дат и лучшие недельные итоги;
- Home показывает текущую неделю из семи слотов;
- прошлые дни не выбираются как архив уровней.

Если московская дата сменилась во время попытки, старый Daily-результат не записывается.

### Endless

Endless появляется после **10 решённых уровней Campaign**.

Один run — это непрерывная последовательность полей:

```text
Board 0–1  → 37 cells
Board 2–4  → 61 cells
Board 5+   → 91 cells
```

После очистки следующая доска загружается автоматически. Размер больше 91 клеток не растёт; дальше повышается профиль сложности.

Главный результат — **сколько досок очищено**. В продукте больше нет очков, множителя серии, combo или фарма score.

Сохраняются два рекорда:

- лучший clean/unassisted run — основной `Best` на Home;
- лучший assisted run — отдельная статистика и никогда не заменяет clean best.

## Undo, Hint и Rescue

В игре больше нет Dust, Shop или расходуемого booster inventory.

- `UNDO` — бесплатный откат последнего удаления; сам по себе не портит Clean и не делает Endless assisted.
- `RESTART` — бесплатный перезапуск текущего поля/попытки с восстановлением права на Clean.
- `HINT` — сначала solver обязан найти маршрут до полной очистки; только после этого, если режим требует rewarded, показывается реклама и затем подсвечивается проверенный ход.
- `RESCUE` — доступен только в настоящем тупике: поле не очищено и легальных ходов `0`. Solver сначала обязан найти безопасную историческую позицию.

Tutorial и первые 5 Campaign levels используют бесплатную onboarding-помощь. Начиная с Campaign Level 6, а также во всём Daily/Endless, Hint/Rescue выполняются только после подтверждённого rewarded callback.

Rescue можно использовать один раз на Campaign/Daily attempt и один раз за весь Endless run. В Endless Hint или Rescue навсегда помечают run как assisted; после Rescue следующий настоящий dead end завершает run.

## Что удалено из старого продукта

Текущий runtime **не содержит**:

- Dust economy;
- Shop;
- покупаемых Hint/Undo/Rescue;
- campaign score;
- Endless point score и streak multiplier;
- публичного/local leaderboard;
- старой 24-уровневой mechanic progression;
- старых mechanic-progression cards/gates;
- публичных shape-family campaign contracts.

Если старый документ или архив говорит обратное, он устарел.

## Игровое поле и правила

Точные правила зафиксированы в [RULES_AUDIT.md](RULES_AUDIT.md). Ключевые моменты:

- фишка свободна, когда в кольце из шести соседей есть минимум три подряд пустые позиции;
- позиции за краем пластины считаются пустыми для этой геометрии;
- четыре стихии парятся сами с собой;
- Salt парится с Salt или одной стихией;
- Vitae ↔ Mors;
- Quicksilver парится с металлами до Silver, но не с Gold;
- металлы открываются строго `Pb → Sn → Fe → Cu → Ag → Au`;
- свободный разблокированный Gold снимается один.

Renderer не должен дублировать или ослаблять правила из `GardenBoard`.

## Сохранения и Яндекс Игры

Campaign progress, Daily progress, Endless records и Settings используют общий player-data storage boundary. На площадке он гидратируется из Yandex Player Data; локально есть browser/in-memory fallback.

Сохраняются также язык (`RU/EN`) и общий sound on/off.

## Текущий визуальный статус

Финальный стиль пока **не выбран**.

Текущий runtime должен оставаться функциональным и читаемым на Phaser primitives до playtest acceptance. **Physical Premium / Club Table** и **Physical UI Factory** заморожены как эксперимент: их инструменты/ассеты могут оставаться в репозитории, но игра не должна зависеть от premium texture/frame names, Blender output или factory rasters.

Desktop, phone portrait и phone landscape должны оставаться полностью управляемыми экранными кнопками; клавиатура не может быть единственным способом навигации.
